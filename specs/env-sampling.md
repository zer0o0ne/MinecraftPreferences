## Notation
- $\Delta$ — `delta` of the env's clips config, ticks; $50\Delta$ ms per ordinary interval; $n$ — `steps`, agent steps per trajectory/shard; $d$ — the absolute soft deadline on `time.perf_counter()`'s scale.
- $k\ge0$ — trajectory/shard index and RL cycle number; $j=0..n-1$ — step index within a shard; $t=kn+j$ — global action index of the endless timeline. $s_t$ is the `EnvState` before $a_t$; `next_step` is the next global action index, $(k+1)n$ after shard $k$.
- $(Y_t,C_t)$ — the real latent history up to $s_t$, oldest first, capped at the last $L$ = `min(perception.history, perception_data.states)`, using the perception config named by pretrain and the dataset config named by sampling; the same $L$ sets the perception-stream restart period; $z_t=Y_t[0,-1]$. $Y$ has shape $(1,m,D)$, $C$ has shape $(1,m,|A|+1)$ with the same $m$; $C$ always has $Y$'s floating dtype and device, including append, cap and restore. $C_0$ ends with the no-action row, later real rows append the one-hot of the action just executed.
- $\mathcal{T}_t$ — the MCTS tree after `decide` at $s_t$; $a_t,p_t$ — the returned `Decision`; $\widehat{\Delta z}_t=x_v-x_{\mathrm{root}}$ for the root child $v$ with action $a_t$, before re-rooting.
- $\tau$ — one trajectory of $n$ steps; $Y_\tau$ — its first real history, used for trajectory-start preferences; $H_{t+1}$ — the real history after encoding $s_{t+1}$. A stable raw reference is `StateRef(episode=f"{cfg.out_dir}#{k:06d}", index=t)` of `specs/rl-preference-pairs.md`; the global index remains continuous across episodes.
- Config `configs/runtime/sampling.yaml` → `@dataclass(frozen=True) class SamplingConfig`, fields in order `pretrain`, `env`, `mcts`, `perception_data`, `out_dir` (non-empty relative path strings without `..`, kept as written and resolved against `REPO`), `steps` ($n$, `positive_int`), `seed` (numpy decision RNG, integer $0..2^{32}-1$), `safety_limit` (ms, number $\ge0$, with $50\Delta-$ `safety_limit` > 0). `config_mapping` rejects missing/unknown keys and violated constraints with `ValueError`. `min_n_sampling` belongs to `MctsConfig`, with $1\le$ `min_n_sampling` $\le$ `simulations`.

## Behaviour
(1) Construction [U,A]: block 13 constructs, owns, checkpoints and closes the sole `Env`; `Sampler` only receives it, and `SamplingConfig.env` is read for the clips $\Delta$. With no supplied modules, `finished_run` checks the pretrain output (marker `complete`), `build_modules(..., paired=True, device=pretrain.device)` builds $\phi,\pi,P$, their entries of pretrain `model.pt` are loaded with `torch.load(..., map_location="cpu", weights_only=True)`, and the model file's SHA-256 is their fingerprint. Block 13 may instead supply the current $\phi,\pi,P$ and their fingerprint for a later RL cycle. In both cases call `eval()` on all three, build `PhiStream(phi, L)` and $\alpha$ from `configs/models/perception.yaml` in $\phi$'s latent dtype/device. Enforce `check_lengths(L, policy_cfg, preference_cfg, paired=True, index_dir=cfg.perception_data)`. All direct preference calls are under `torch.no_grad`, as is any sampling inference not already covered internally by `PhiStream` or MCTS.

(2) Explicit reset [U,A]: block 13 calls `reset()` once after construction, then may call `sample()` repeatedly; `sample()` before that reset or a second `reset()` raises `RuntimeError`. At zero complete shards, `reset()` calls `env.reset()`, keeps the raw $s_0$ for the first timed action, creates a new stream and `numpy.random.default_rng(seed)`, and sets `next_step=0`; no latent history or tree exists yet. At nonzero complete shards it loads the last complete `state.pt`, calls `env.restore(state.observation, state.env)` before any model-fingerprint branch, never calls `env.reset` and never reinitialises the RNG. Thus both a newly constructed and an already initialised matching wrapper receive the saved `EnvState`, raw completion baselines, physical GUI flag and cursor without simulator commands, ticks or classification. With an unchanged model fingerprint it restores the raw current state, history, tree and stream exactly. With a changed fingerprint it creates a new stream and loads the raw history ending at the current state; the next timed action re-encodes the suffix since its stream restart and replaces the real history and `tree.base`, while the root and all descendant coordinates, cached values and $N,Q$ deliberately remain stale.

(3) Action choice [U]: read $t_0$ immediately on entry, before any preparation or transfer, and compute $d$. Encode raw states not already encoded through $s_t$ by `PhiStream.step`, append their latent/action rows and cap the history at $L$. Construct the first tree by `Tree(LatentHistory(Y_t,C_t))`. After an ordinary within-trajectory action, call `advance(tree, a_{t-1}, H_t, alpha, mcts.epsilon)` now; after a changed-model restore only replace `tree.base` as in (2). A state already encoded and advanced at a trajectory boundary is not encoded or advanced again. Pass $d$ to `decide`; after it returns, record `elapsed_ms` = $1000(\text{perf_counter()}-t_0)$. Environment execution and preference computations are outside this measurement.

(4) Revised MCTS loop [U,A]: `MctsConfig` gains `min_n_sampling` after `simulations`; `decide` gains a required last argument `deadline: float`. Before starting each simulation, if the number completed during this call is at least `min_n_sampling` and `perf_counter() >= deadline`, stop; otherwise run one complete simulation. The final draw and probability vector follow `specs/mcts.md` (6), including current-mask filtering of a reused root. `min_n_sampling` takes priority even when $d$ has already passed. Every pre-existing caller, including the MCTS latency test, passes `deadline=float("inf")` unless it tests the deadline.

(5) Environment and delayed record [U,A]: immediately after `decide`, serialize an independent CPU snapshot of $\mathcal{T}_t$ and compute $\widehat{\Delta z}_t$ before any re-rooting. If a preceding step record is pending, complete it now from $H_t$: $\Delta z_{t-1}=z_t-z_{t-1}$ and the two preferences of (6), then write it and advance the bar. Execute the current $a_t$ by `env.step` and retain its raw result as $s_{t+1}$; its record remains pending. After the last environment step of a trajectory only, encode $s_{t+1}$ outside the action-choice measurement, append/cap the history, call `advance(tree, a_t, H_{t+1}, alpha, mcts.epsilon)`, complete and write the last record, capture `env.continuation()` at that valid boundary, and write `state.pt` including it. This successor is reused at the next trajectory boundary without a second encoding.

(6) Preference outputs [U,A]: the orientation is result first. Close: $(s_c,t_c)=P(Y_{t+1},Y_t)$. Trajectory start: $(s_\tau,t_\tau)=P(Y_{t+1},Y_\tau)$, where $Y_\tau$ is fixed at the first action of the trajectory containing action $t$. Store both logits of each call as floats. This supplies both kinds named by RLS-3 without a second order or sigmoid.

(7) Shard and rerun [U,A]: trajectory $k$ is staged by `write_shard(REPO / cfg.out_dir / "shards", k)` and published after its $n$ records and `state.pt`. A `.part` left by an interruption is removed on rerun, and that trajectory is repeated from the state of shard $k-1$; complete shards are never rewritten. The caller supplies the externally matching world state; block 9 restores the Python wrapper from its `state.pt`, while simulator world snapshot/restore remains outside both blocks 9 and 13. The RNG, real history, current tree, perception stream and wrapper continuation are restored from the shard, so no earlier trajectory is replayed. A legacy `state.pt` lacking any required wrapper or per-layer cache field raises `RuntimeError("incompatible sampling state")`; it is not partially restored and does not call `env.reset()`.

(8) Progress [U,A]: one `tqdm` bar on stderr per `sample`, description `env sampling`, unit `step`, total $n$, initial 0 also when repeating a partial trajectory. Advance after each complete step record is written; no per-item lines or stdout output.

## Interface
- `src/mcpref/runtime/sampling/config.py`: `SamplingConfig`; `def load_config(path: Path) -> SamplingConfig`.
- `src/mcpref/runtime/sampling/models.py`: `@dataclass(frozen=True) class SamplingModules` (`phi: Phi`, `pi: Policy`, `P: Preference`, `fingerprint: str`); `def load_pretrained(cfg: SamplingConfig) -> SamplingModules`; `def encode_stream(stream: PhiStream) -> dict`; `def decode_stream(phi: Phi, states: int, value: dict, device: torch.device) -> PhiStream`.
- `src/mcpref/runtime/sampling/runner.py`: `class Sampler`; `__init__(cfg: SamplingConfig, env: Env, modules: SamplingModules | None = None)` (`None` calls `load_pretrained`); `reset() -> None`; `sample() -> Path` — one trajectory shard of (2)–(8), returning its complete directory.
- `src/mcpref/runtime/sampling/shards.py`: `@dataclass(frozen=True) class StepRecord` (`index: int`, `before: EnvState`, `after: EnvState`, `action: int`, `probabilities: Tensor` (CPU float64, $(|A|,)$), `delta: Tensor`, `predicted: Tensor` (both CPU, $(D,)$, latent dtype), `elapsed_ms: float`, `preference_close: dict[str, float]`, `preference_start: dict[str, float]`, `tree: dict` — the independent primitive snapshot); `@dataclass class SamplerState` with fields in order (`observation: EnvState`, `env: EnvContinuation`, `history: LatentHistory`, `tree: Tree`, `rng_state: dict`, `next_step: int`, `stream: PhiStream`, `fingerprint: str`); `@dataclass(frozen=True) class RawHistory` (`states: list[EnvState]`, `actions: list[int | None]`, `restart: int`).
- `src/mcpref/runtime/sampling/shards.py` callables: `def write_step(directory: Path, local: int, record: StepRecord) -> None`; `def write_state(directory: Path, state: SamplerState) -> None`; `def load_state(out_dir: Path, phi: Phi, states: int, device: torch.device) -> SamplerState`; `def load_step(out_dir: Path, index: int) -> StepRecord`; `def read_history(out_dir: Path, index: int, states: int) -> RawHistory` — let `history_start` = $\max(0,t-L+1)$ and `restart` = the greatest global state index $\le$ `history_start` divisible by $L$; return every raw state from `restart` through $s_t$ (at most $2L-1$) and their preceding actions (`None` only for the no-action row at $t=0$). A downstream encoder processes this full context and takes the last $L$ latents; changed-model restoration uses only the suffix from the current state's own stream restart. `record_cache(out_dir: Path, capacity: int)` is a context manager that shares one metadata value and a bounded LRU of immutable CPU `StepRecord`s between both readers for its dynamic extent and clears them on every exit. Readers cross shard boundaries, load one shard at a time apart from this bounded record cache and never materialise the trajectory dataset.
- `src/mcpref/runtime/mcts/config.py`, `search.py`: the revision (4); the full signature is `decide(tree: Tree, mask: np.ndarray, pi: Policy, P: Preference, alpha: Tensor, cfg: MctsConfig, rng: np.random.Generator, deadline: float) -> Decision`.
- `configs/runtime/sampling.yaml`, `configs/runtime/mcts.yaml`: starting values `configs/training/pretrain/config.yaml`, `configs/runtime/env.yaml`, `configs/runtime/mcts.yaml`, `configs/datasets/perception-data.yaml`, `out_dir` = `data/sampling`, `steps` = 1000, `seed` = 0, `safety_limit` = 25.0, `min_n_sampling` = 4.
- Consumes: pretrain `model.pt` or supplied current modules, the `Env` and its externally matching world, all named configs. Produces `{out_dir}/run.json` and `{out_dir}/shards/<name(k)>/` for R2–R4 and block 13.

## Datasets
- `run.json`: top-level `config` (the mapping as written), `sha256`, `models`, `counts`. The ordered `sha256` keys are `config`, `pretrain_config`, `pretrain_model`, `env`, `mcts`, `perception_data`, `perception`, `action_mask`, `policy`, `preference`, `engine`, `classifier`, `clips`, `vpt_actions`, `gui_screens`; transitive paths come from the loaded configs. `models` maps each published shard name to its supplied/pretrain model fingerprint. Static fingerprints are checked by `check_fingerprints` before a rerun.
- `run.json` is created by `write_json` before the first environment reset and rewritten by `write_json` after each published shard. On continuation, `complete_shards` repairs `counts` to {`trajectories`: $k$, `steps`: $kn$} and `models` is rebuilt from each shard's `state.pt`, one at a time, before sampling resumes.
- Each shard holds exactly one trajectory of $n$ steps. Every `torch.save` receives the primitive mapping below; every `torch.load` uses `map_location="cpu", weights_only=True`. Serialized tensors are CPU; decoded histories, trees and cache tensors move to the model device, while stream grids remain on the CPU.
- `steps/<name(j)>.pt`: the StepRecord mapping {`index`, `before`, `after`, `action`, `probabilities`, `delta`, `predicted`, `elapsed_ms`, `preference_close`, `preference_start`, `tree`}. Each preference value is {`succ`: float, `inc`: float}. The local filename uses $j=t-kn$; `index` stores global $t$. A record is written when its successor is encoded, so at most one pending step record is held besides current sampler state.
- An `EnvState` mapping is {`frame`: uint8 tensor $(H,W,3)$, `line`: its primitive mapping, `gui`: bool, `cls`: string or null, `hotbar`: int, `mask`: bool tensor $(|A|,)$}; decoding returns numpy arrays for `frame` and `mask`. An `EnvContinuation` mapping is {`info`: {`isGuiOpen`: bool, `custom`, `mine_block`, `use_item`: primitive cumulative mappings}, `cursor`: two floats, `held_action`: int or null}; no `EnvState` is duplicated inside it. `held_action` is the action index when the boundary follows a long action that reached $\Delta$ without completion, and null otherwise. A history mapping is {`Y`, `C`: tensors of Notation}. A preference pair is never a tuple or a sigmoid output.
- A tree mapping is {`root`: node, `base`: history, `policy`: the full root policy probability list captured by the existing root expansion, or null only in a legacy/incomplete snapshot}. Block 33 uses this list without another forward; legacy records without it are unavailable rather than backfilled. A node mapping is {`z`, `x`: tensors $(D,)$, `action`: int or null, `prior`: float or null, `shift`: tensor $(D,)$ or null, `children`: list in expansion order, `n`: int, `mean`: float, `value`: float or null, `policy`: the full probability list captured when this node was expanded, or null}; `parent` is not serialized and is rebuilt on decoding. There is no object pickle of `Tree`, `Node`, `EnvState` or `EnvContinuation`.
- `state.pt`: {`observation`: encoded current raw state, `env`: encoded `EnvContinuation`, `history`, `tree`, `rng`: the primitive `rng.bit_generator.state`, `next_step`: global int, `stream`, `fingerprint`: string}. It is written after the last step.
- `stream` = {`ids`: list of ints, `grids`: list of CPU tensors, `cache`: one entry per `DynamicCache.layers` element in model layer order, `first`: primitive first line}. Every cache entry has exactly {`keys`, `values`, `sliding`, `cumulative_length`, `conv_states`, `recurrent_states`}: tensor fields are independent CPU tensors or null, and `cumulative_length` is an int or null. K/V/sliding are null for Qwen3.5 linear-attention-only layers; conv/recurrent are their state index 0 tensors; full-attention conv/recurrent fields are null. A sliding K/V layer stores its actual cumulative length even when only its last `sliding_window - 1` K/V tokens remain. No layer is skipped, including layers with both attention and linear state.
- `decode_stream` constructs `DynamicCache(ddp_cache_data=<K/V tuples in layer order, including a third sliding entry when non-null>, config=phi.backbone.config)`. For each non-null conv state it calls `update_conv_state(tensor.to(device), layer_idx=<its index>, state_idx=0, conv_kernel_size=<saved last dimension>)`; for each non-null recurrent state it calls `update_recurrent_state(tensor.to(device), layer_idx=<its index>, state_idx=0)`, thereby restoring initialization and previous-state flags rather than assigning tensors directly. After K/V decoding it assigns each saved sliding `cumulative_length` to that same layer, then restores `ids`, CPU `grids` and `first` without $\phi$ or its weights.
- A rerun starts at `complete_shards`; a partial trajectory is repeated. Exact continuation requires the caller's matching world state and deterministic engine/network backend. Nondeterminism of the real engine and GPU backend is excluded from the exact-rerun promise; CPU/fake-env equality is tested instead [U].

## Tests
- CPU with fake env/networks: pretrain and supplied-module loading/eval/fingerprints; explicit reset protocol; unchanged-model restore and changed-model stream/history rebuilding with stale tree statistics; the no-gradient calls and length checks; global/local indices and the cross-shard raw reader.
- Deadline: $t_0$ precedes current-state perception/history/advance; MCTS before-simulation stopping, minimum priority, expired deadline, one running simulation allowed to finish, unchanged RNG draw/probabilities with an infinite deadline; environment and delayed preferences are outside `elapsed_ms`.
- Histories: exact $Y,C$ shapes/dtypes/devices, no-action/action rows, cap at $L$; real/predicted shifts; both preference calls, argument order and per-trajectory $Y_\tau$; ordinary and final advance order; delayed record completion and final successor reuse. Reused-root masking follows `specs/mcts.md` Tests: no forbidden action or probability mass reaches `Env.step` or `StepRecord`.
- Primitive round trips of every EnvState/EnvContinuation/history/tree/node/stream/cache field, parent/child order and per-step tree independence; no arbitrary-object serialization; explicit `weights_only=True` loads. A tiny real `Qwen3_5Config` creates a `DynamicCache` with linear-attention and full-attention layers, without running model inference. Distinct float64 K/V/conv/recurrent tensors retain layer order, values, dtypes and CPU placement; encode(decode(encode)) is identical and previous-state flags are restored. The same next conv/recurrent/K-V update on original and decoded caches gives exact CPU equality.
- Sliding continuation: after six tokens with window four, only the permitted trailing K/V tokens remain but `cumulative_length=6` and mask sizes/offsets round-trip exactly; the next update also matches the original. A complete mixed-cache `state.pt` passes through actual `write_state`/`torch.save`/`load_state(weights_only=True)`, and legacy missing fields produce the explicit incompatibility error without reset.
- Fresh-process wrapper recovery uses the real `Env` with a fake simulator, not a step-ready `FakeEnv`: an uninterrupted control and a newly constructed `Env`/sampler restored at the same external fake-world boundary have identical `before == previous_after`, actions, low-level traces, global indices, history/tree/RNG and records. Restore has zero reset/commands/hidden ticks and covers both unchanged and changed model fingerprints. A boundary after an unfinished long action verifies exact traces when repeating and when changing the action. Complete shards are never rewritten.
- Atomicity and recovery: interrupted `.part` repeated without rewriting complete shards; run file created before reset; counts/models repaired after a crash between shard publication and run rewrite; every ordered fingerprint; config validation and starting values; bar total/advance and no stdout.
- Real Spark integration: one short trajectory with the actual mixed-cache models and env, checking action output, shard readability, continuation in a fresh process with an externally matching world, and median/tail `elapsed_ms`.
