## Notation
- $A$, $|A|$, $\iota(a)$ — the actions and their indices of `specs/action-mask.md`; $n_{allowed}$ — the number of actions allowed at a node; $l$ = `width`, $S$ = `simulations`, $d_{max}$ = `depth`, $c$ = `c_puct`, $\gamma$ = `discount`, $\tau$ = `temperature`, $m_{min}$ = `min_p`, $\varepsilon$ = `epsilon`.
- A history $H=(Y,C)$: $Y\in\mathbb{R}^{1\times n\times D}$ latent rows oldest first, $C\in\mathbb{R}^{1\times n\times(|A|+1)}$ the corresponding executed-action weights. A one-hot action row is used in an imagined record exactly as in a real record; the networks apply their own history limits $L_\pi,L_P$. $(Y_{real},C_{real})$ is the observed real history and $z_{real}=Y_{real}[0,-1]\in\mathbb{R}^D$ its last latent.
- $\sigma(x)=1/(1+e^{-x})$ — the logistic sigmoid of `specs/preference.md`; $\lambda\in\mathbb{R}^{|A|}$ — the policy logits of `specs/policy.md` (5).
- Each node $v$ has two latents of shape $(D,)$: $z_v$, the working latent used in the histories given to $\pi$ and $P$, and $x_v$, the exact predicted latent used only to accumulate the discrepancy from reality. At a new real root $z_v=x_v=z_{real}$.
- Each non-root node has its incoming action $a_v$, visit count $N_v\in\mathbb{Z}_{\ge0}$, mean backed-up value $Q_v$, children in expansion order, and a cached value $V_v$ once evaluated. A policy-generated node also has prior $p_v$ and quantised shift $q_v$; a new real child has neither. Initially $N_v=0$, $Q_v=0$, children empty, no cached value. The root has $V_{root}=0$.
- $Q_\varepsilon(\delta)$ — the elementwise quantisation of a latent shift $\delta$: in $u=\alpha\odot\delta$, $Q_\varepsilon(\delta)=\alpha^{-1}\odot(\varepsilon\,\mathrm{round}(u/\varepsilon))$; `torch.round(..., decimals=0)`, ties to even. Equality of quantised vectors is exact, with no further tolerance.
- A node $v$ matches a real latent $z$ iff $Q_\varepsilon(x_v-z)=0$ as a vector. This compares the accumulated exact states, not the individual rounded shifts.
- Config `configs/mcts.yaml` → `@dataclass(frozen=True) class MctsConfig`, fields in this order: `simulations`, `min_n_sampling`, `depth`, `width`, `latency_calls` (`positive_int`); `c_puct` (`number`, ≥ 0); `discount` (`number`, in (0, 1]); `temperature`, `min_p`, `epsilon`, `latency_ms`, `latency_fail_ms` (`positive`); $1\le$ `min_n_sampling` $\le$ `simulations`; read by `config_mapping`, missing/unknown keys or violated constraints → `ValueError`.

## Math
(1) History of a node: start with the root's base $(Y,C)$; for every imagined edge on the path append its child's $z_v$ to $Y$ and the one-hot of its incoming action to $C$. The root after re-rooting takes the reused child's history as its base. Exact latents $x_v$ are not network inputs.
(2) Value of a leaf $v$ [U]: with $(s,t)=P(Y_v,Y_{\operatorname{parent}(v)})$, $p_\succ=\sigma(s)$, $p_{inc}=\sigma(t)$,
$V_v=(p_{inc}+m_{min})(2p_\succ-1)$. The mathematical root value is 0 without a call of $P$; the root's `Node.value` field is never read and may retain a stale value or `None`. A cached $V_v$ is reused while the tree and networks remain unchanged; coordinates and cached values are not recomputed after re-rooting or a change of $\phi$.
(3) Expansion of an evaluated leaf $v$ at depth $<d_{max}$: one `readout` of its working history, then `logits` and $\pi=\mathrm{softmax}(\lambda)$. At the root, masked actions are excluded using the observed root mask; at imagined nodes every action is allowed. Take the $\min(l,n_{allowed})$ highest-probability allowed actions, probability ties broken by the lower action index. Their priors are the original softmax entries, not renormalised. For each action $a$ in that order, one batched `shift` call gives $\delta(a)$; the child has $q_v=Q_\varepsilon(\delta(a))$, $z_v=z_{parent}+q_v$, $x_v=x_{parent}+\delta(a)$, prior $\pi(a)$. A node at depth $d_{max}$ is evaluated but never expanded.
(4) Selection [U]: from the root, while the current node has children, select the child $a$ maximising
$Q_a+c\,p_a\,\frac{\sqrt{\sum_b N_b}}{1+N_a}$,
where the sum is over the node's children and an unvisited child has $Q_a=0$. Ties go to the earliest child in expansion order. The remaining node is the leaf of the simulation.
(5) One simulation: find the leaf by (4), evaluate it once by (2), expand it by (3) when below $d_{max}$, then back up its value. For a leaf at depth $d\ge1$ and path edges $e_0,\dots,e_{d-1}$ from the root, edge $e_j$ receives $w_j=\gamma^{d-j}V_v$: $N_{e_j}\leftarrow N_{e_j}+1$, $Q_{e_j}\leftarrow Q_{e_j}+(w_j-Q_{e_j})/N_{e_j}$. No edge is updated for a root leaf.
(6) Decision [U]: before each simulation, if at least `min_n_sampling` simulations have completed during this call and `time.perf_counter() >= deadline`, stop; otherwise run one complete (5). Thus at most $S$ simulations run, the minimum takes priority over an already expired deadline, and a running simulation is never interrupted. For root child $v$, $w_v=N_v^{1/\tau}$; if every $w_v=0$, $w_v=1$ for every child. Draw the child by `rng.choice(len(children), p=w/sum(w))` in child order, using the caller's `numpy.random.Generator`. Return its action and the full $|A|$ float64 vector with $w_v/\sum_b w_b$ at the indices of root children and 0 elsewhere — the actual probability of the executed action for PPO.
(7) Re-root after the real action and observation [U]: let $a$ be the executed action and $z=z_{real}$ the new real latent. First test the root's child of $a$, then every other child in expansion order, by Notation's exact-state match. On the first match, make that child the root, set its `parent` to `None` and otherwise keep its $z_v,x_v$, descendants, cached values and $N,Q$ unchanged; its history by (1) becomes the new base. If its incoming action was $b\ne a$, set its incoming action to $a$ and replace the last row of the base $C$ with the last row of $C_{real}$; every other history row is unchanged. If none matches, create a new empty child of $a$ with $z_v=x_v=z$, make it the root with `parent=None` and use the real observed history $(Y_{real},C_{real})$ as its base; the old tree is discarded. Thus small errors remain in $x_v$ and can accumulate, while a critical accumulated discrepancy rebases the tree to reality.

## Domain
- $\pi$ and $P$ are in eval mode on one device, called under `torch.no_grad`; their inputs finite, in their dtype and on their device. The real, exact and working latents have the same floating dtype and device. $\alpha$ has shape $(D,)$, positive entries and that same floating dtype and device; `quantize` preserves `delta`'s dtype and device. The root mask is a bool vector over $A$ with at least one allowed action; $l\le|A|$. Histories are non-empty; real $C$ follows `specs/policy.md`.
- One decision mutates its tree and advances the supplied RNG, but no other state; there is no concurrent use of that tree or RNG. A tree surviving a network update keeps its old coordinates and values (Q MCTS-8). The caller owns the decision RNG and saves its state with the trajectory state. The deadline is absolute on `time.perf_counter()`'s scale; the minimum simulation count takes priority over it.

## Behaviour
- The timeline's first state starts a tree by `Tree(real)`. `decide` performs (1)–(6), mutating the tree and advancing the supplied RNG. After the environment step, `advance` performs (7), replacing `root` and `base` in the supplied `Tree` and returning that same object.
- The current tree is state held between the decisions of one trajectory. Past trees and their RNG state are written with the trajectory shards by block 9; this block has no files of its own.
- Latency (soft): $\pi,P$ built once from `configs/policy.yaml`, `configs/preference.yaml` with their own seeds, in eval mode, float32 on the Spark's GPU; $\alpha$ from `configs/perception.yaml`, moved to that device and dtype. After `torch.manual_seed(0)`, one real history is generated: $Y$ = `torch.randn(1, 12, D, device=<the GPU>, dtype=torch.float32)`, $C$ = the one-hot of no action in every row, $D$ = `len(alpha)` = 40, $L_\pi=L_P=12$. The root mask is `state_mask(masks, gui=False, cls=None, pitch=0.0, hotbar=0)` for `load_masks` of `configs/action-mask.yaml`. Every measured call, including the warm-up, uses a fresh `Tree` of that history, `numpy.random.default_rng(0)` and `deadline=float("inf")`. After one warm-up decision, the median of `latency_calls` fresh decisions with the starting $S,l,d_{max}$ is at most `latency_ms`; the GPU test prints it and fails only above `latency_fail_ms`. Timing covers `decide` under `torch.no_grad`, in this exact order: `torch.cuda.synchronize()`, `start = time.perf_counter()`, `decide(..., deadline=float("inf"))`, `torch.cuda.synchronize()`, `stop = time.perf_counter()`.

## Interface
- `src/mcpref/mcts/config.py`: `MctsConfig`; `def load_config(path: Path) -> MctsConfig`.
- `src/mcpref/mcts/tree.py`: `@dataclass(frozen=True) class LatentHistory` (`Y: Tensor`, `C: Tensor`) with the shapes and floating dtype/device of Notation. `@dataclass class Node` with fields, in order, `z: Tensor`, `x: Tensor` (both shape $(D,)$), `action: int | None`, `prior: float | None`, `shift: Tensor | None` (shape $(D,)$ when present), `parent: Node | None`, `children: list[Node]`, `n: int`, `mean: float`, `value: float | None`. `@dataclass(init=False) class Tree` with fields `root: Node`, `base: LatentHistory` and `__init__(self, real: LatentHistory)` — the first real root: `z=x=real.Y[0, -1]`, action/prior/shift/parent `None`, no children, `n=0`, `mean=0.0`, `value=0.0`, `base=real`; `Node` is otherwise internal to the tree functions. `def history(tree: Tree, node: Node) -> LatentHistory` — (1); `def quantize(delta: Tensor, alpha: Tensor, epsilon: float) -> Tensor` — $Q_\varepsilon$ on `delta` of shape $(\dots,D)$, `alpha` of shape $(D,)$, returning the same shape, dtype and device as `delta`; `def advance(tree: Tree, action: int, real: LatentHistory, alpha: Tensor, epsilon: float) -> Tree` — (7).
- `src/mcpref/mcts/search.py`: `@dataclass(frozen=True) class Decision` (`action: int`, `probabilities: np.ndarray` of shape $(|A|)$, dtype float64); `def decide(tree: Tree, mask: np.ndarray, pi: Policy, P: Preference, alpha: Tensor, cfg: MctsConfig, rng: np.random.Generator, deadline: float) -> Decision` — (1)–(6), `mask` a bool array of shape $(|A|)$ and `alpha` of shape $(D,)$, with `pi` and `P` supplied by the caller and the required last absolute deadline.
- `configs/mcts.yaml`: the starting values below. Package map: `mcts` → R1 → `specs/mcts.md`.
- Consumes: the current real latent history and root mask from block 9; $\pi$, $P$ and $\alpha$ from blocks 6, 5, 2. Produces: the decision, its action-probability vector and the current tree for block 9. Datasets, checkpoints, files and progress bars of its own: none.
