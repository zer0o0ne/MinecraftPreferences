## Notation
- $A$ — `action_names(screens)` of `specs/vpt-gui-actions.md`: the 34 `WORLD_ACTIONS`, then `close`, `left_click_`$i$, `right_click_`$i$, `shift_click_`$i$, `double_click_`$i$ for $i = 1..n_{max}$ ($n_{max} = 90$, $|A| = 395$); a mask is a `numpy` bool array over $A$ in that order, true = allowed; $i$ — an element's canonical index.
- State features: $g$ — a GUI is open (the GUI flag: `gui` of `clip.json`, which applies the first-line rule of `specs/vpt-gui-actions.md`; in the environment, block 14's flag under the same rule, [U]); $k$ — the screen class when $g$ (a class of the catalogue $\mathcal{K}$, or `other`); $\theta$ — the pitch in degrees (a mouse move down increases it; `turn_down` increases it); $h \in 0..8$ — the selected hotbar slot.
- $\mathcal{D} = \mathcal{K} \setminus \{$`death`, `pause`$\}$ — the classes of (2); `death` has the data-only mask (2'); `pause` and `other` are outside the domain (the data excludes their states, `specs/vpt-gui-actions.md` (8); the environment never acts on them).
- $E_k$ — the elements of class $k$ (`elements` of the catalogue): canonical index, name, kind (`slot` or `button`).
- Right-handled button ([G]): a button whose name fully matches `(book_recipe|option|recipe|pattern)_[0-9]+` — in the catalogue the recipes of `inventory_book`, `crafting_book`, `furnace_book`, the options of `enchanting_table`, the recipes of `stonecutter`, the patterns of `loom`, and no other element; every other button handles only the left button; no slot is a right-handled button.
- $\theta_{max}$ — `pitch_limit` (the game's pitch clamp).
- Clip: `info` — its parsed `clip.json`, `lines` — its parsed `lines.jsonl` (the `Clip` of `specs/pretrain.md`); $L$ — `len(info["states"])`; $s = 0..L-1$ — a state of the clip.
- Config `configs/action-mask.yaml` → `@dataclass(frozen=True) class ActionMaskConfig`, read with `config_mapping` (a missing or unknown key → `ValueError`): `screens` (a path string, checked at load by `repo_path` of `mcpref`, kept as written and resolved against the repository root where read), `pitch_limit` (`number` of `mcpref`, > 0); violated constraints → `ValueError` at load.

## Math
(1) World ($g$ false) — [U] 2026-10-15, 2026-10-21: every world action allowed except `turn_up` when $\theta \le -\theta_{max}$, `turn_down` when $\theta \ge \theta_{max}$, and `hotbar_`$(h + 1)$; every GUI action masked.
(2) GUI ($g$ true, $k \in \mathcal{D}$) — [U] 2026-10-21, [G]: every world action masked; `close` allowed; for each element $e \in E_k$ with index $i$: `left_click_`$i$ and `shift_click_`$i$ allowed, `right_click_`$i$ allowed iff $e$ is a slot or a right-handled button, `double_click_`$i$ allowed iff $e$ is a slot; every click on an index that no element of $E_k$ has is masked.
(2') Death screen ($g$ true, $k$ = `death`; only in the clips collected before this block, [U]): `left_click_`$i$ and `shift_click_`$i$ of the element named `respawn` allowed; every other action masked.
(3) Outside the domain ($g$ true, $k \in \{$`pause`, `other`$\}$): `ValueError(f"no mask for the screen {k}")`.
(4) Masks of a clip: state $s$ has $g$ = `info["gui"][s]`, $k$ = `info["classes"][s]`, $\theta$ = `info["pitch"][s]`, $h$ = `lines[info["states"][s] - info["states"][0]]["hotbar"]` (`lines.jsonl` holds the lines of the clip's span from its first state's line, `specs/perception-data.md`); row $s$ = (1)–(3) of state $s$.
(5) Latency ([U] 2026-10-20: every component on the per-step path states a budget; [U] 2026-10-21: soft): target — the median over 100 calls, after one warm-up call, each timed by `time.perf_counter`, of `state_mask` on a world state and on a GUI state of each class of $\mathcal{D}$, at most 0.1 ms each on the CPU of this machine; the test fails only above 1 ms (a guard against gross regressions) and prints the medians.
(6) Forbidden human action ([U]): an action of the human data is forbidden iff the mask of the line where it is pressed forbids it — for a GUI segment of `specs/vpt-gui-actions.md` its line's ($g$ true, $c_t$, $\theta_t$, $h_t$), for a world segment of `specs/vpt-actions.md` its line's ($g$ false, $\theta_t$, $h_t$), for a turn of an interval the world mask at the interval's first line's $\theta$; (6) does not apply to a line with $g$ true whose class is not in $\mathcal{D}$ or was not classified (a `close` there closes the screen; `close` is allowed in every class of $\mathcal{D}$) [U]; after the revision of block 21 the data holds no forbidden action (Tests).

## Domain
- $g$ false with any $k$ (ignored); $g$ true with $k$ a class of $\mathcal{K}$ or `other`; $\theta \in [-\theta_{max}, \theta_{max}]$; $h \in 0..8$; a clip's `info` and `lines` as written by perception-data or preference-pool.

## Behaviour
- The masks of (2) and (2') depend only on $k$: they are built once per class (and the world mask without its pitch and hotbar terms once) by `load_masks`; a state's mask is a copy of its base with (1)'s three entries applied.
