## Notation
- Classifier $\gamma$: a callable mapping a non-empty list of RGB frames ($H \times W \times 3$, `uint8`, $W$ = `width`, $H$ = `height`, the view (5) of `specs/vpt-gui-frames.md`) to a list of class names of $\mathcal{K} \cup \{\text{other}\}$, one per frame; assumed deterministic per frame (a frame's class does not depend on the rest of its batch); $\gamma_{id}$ — a string naming it, recorded in `run.json`.
- Subsets $S$: the keys of `index_urls`, in config order; initial pool of a subset — its index's `relpaths` with exact repeats removed, each kept at its first occurrence, in index order; active subsets — those with a non-empty pool.
- $g$ — the plan's generator; draw $k = 0, 1, \dots$ — one iteration of (1); $s$ — its subset; $j$ — a pool position.
- Candidate — a popped episode that passes the checks `version` … `options` of (1); a draw ends with its candidate or with an empty pool; its records — the popped episodes in pop order; shard $k$ holds draw $k$.
- Episode $e$: URL stem = the index's `basedir` + its relpath without `.mp4`; its `.jsonl` bytes $J_e$; its lines $\ell_0..\ell_{T-1}$ — the pieces of $J_e$ split on `\n` (a final `\n` ends the last line), each parsed by `json.loads`; its frames $0..T$; `<version>_<stem>` — `episode_name` of its relpath.
- $N$, $m$, $L$ — `n_clips`, `per_episode`, `states`; $h$ — the complete shards; $c$ — the clips in them; $E$ — the records in them.
- JSON files of this block: `json.dumps(value, indent=2)` + `"\n"` (`ensure_ascii` default), `json.loads` to read.
- Config `configs/perception-data.yaml` → `@dataclass(frozen=True) class PerceptionDataConfig`; integers are YAML integers (not booleans), durations YAML integers or floats; violated constraints → `ValueError` at load:
  - access fields (the fields of the same names of `GuiFramesConfig`, same meaning): `index_urls` (a non-empty mapping of strings to strings), `x_ms_version`, `min_version` (strings), `required_options` (a mapping of strings to JSON scalars), `width`, `height`, `fetch_streams` (1–20), `http_timeout`, `http_retries`, `retry_delay`, `ffmpeg` (a string);
  - `ffmpeg_timeout` (s, one whole-episode decode);
  - `clips`, `screens`, `gui_actions`, `overlay` — paths of `configs/clips.yaml`, `configs/gui-screens.yaml`, `configs/vpt-gui-actions.yaml`, `configs/f3-overlay.yaml`; all paths relative to the repository root, resolved against it;
  - `classifier_config` — the path of `configs/gui-classifier.yaml`, a string relative to the repository root, resolved against it; not an output field and not hashed in (8) ($\gamma_{id}$ carries its effect);
  - `states` ($L \ge 2$), `per_episode` ($m \ge 1$), `n_clips` ($N \ge 1$), `seed` ($0 \le$ seed $< 2^{32}$), `workers` (≥ 1), `classifier_batch` (≥ 1), `out_dir`.
- Output fields — the fields whose values change the outputs: `index_urls`, `min_version`, `required_options`, `width`, `height`, `clips`, `screens`, `gui_actions`, `overlay`, `states`, `per_episode`, `n_clips`, `seed`.

## Domain
- `{out_dir}` holds only what this block writes; one run at a time; the readers run while no run does.
- At least one subset; one `basedir` over the indices; no relpath listed by two subsets ([R3]); every line of $J_e$ a JSON object with the fields the composed blocks read; `.jsonl` files end with `\n` ([R6]); not checked.

## Behaviour
(0) Indices: `make_dirs` of `{out_dir}/indices/`; then, in config order: `{out_dir}/indices/<subset>.json` present → used as it is; otherwise the index URL is downloaded with one `GET` (header `x-ms-version`, `follow_redirects=False`; a transport error or HTTP 5xx retried after `retry_delay` up to `http_retries` times; then any status other than 2xx aborts the run); its body must be a JSON object with a string `basedir` and a list `relpaths`, else `ValueError` aborts the run; it is written there by `write_file`.
(1) Plan, $g$ = `numpy.random.Generator(PCG64(seed))`, until $N$ clips are in the shards or no subset is active. Draw $k$: $s$ = the subset at position $g$`.integers(len(active))` of the active subsets in config order; then, repeatedly: $j$ = $g$`.integers(len(pool))`, $e$ = `pool.pop(j)` of $s$'s pool, and the checks below, until $e$ is a candidate or the pool is empty. Checks, the first failing one is the reason: `version` (the relpath's `<version>`, compared as a tuple of integers, is below `min_version`; nothing fetched); `missing` (the options file, URL stem + `-options.json`, answers 404; else the `.jsonl`, URL stem + `.jsonl`, answers 404; the `.jsonl` is not requested when the options file is missing; both by the ranged fetch (f)); `empty` (either file has zero bytes); `malformed` (`json.loads` of the options file or of a line of $J_e$ raises `ValueError`, or the options file is not a JSON object); `options` (a `required_options` key absent from the options file, or whose value differs by Python `==`, so `2` equals `2.0`). The candidate of draw $k$, if any, is processed by (2)–(5) with its own generator `Generator(PCG64([seed, 1, k]))`; its reason is then `video`, `no_clip` or `null` (valid).
(2) Video: the `.mp4` at URL stem + `.mp4` by the ranged fetch (f) (a 404 → reason `video`) into `{out_dir}/staging/<k>.mp4`; pass 1 decodes it with `[ffmpeg, "-nostdin", "-loglevel", "error", "-i", <video>, "-fps_mode", "passthrough", "-f", "rawvideo", "-pix_fmt", "yuv420p", "pipe:1"]`; a decode whose exit code is not 0 or whose stdout is not exactly $(T + 1) \cdot W H \cdot 3/2$ bytes is retried after `retry_delay` up to `http_retries` times, then gives the reason `video`; a decode not ended within `ffmpeg_timeout` is killed and aborts the run with `TimeoutError` ([U]: the reasons stay independent of the machine's load; a rerun tries again). Pass 1 keeps frame 0 and every frame $t \le T - 1$ with `isGuiOpen` of $\ell_t$ true.
(3) Classes: every frame is classified at most once per episode, its class kept for the rest of the episode; the frames of `needed_frames` are classified in their order, in consecutive chunks of `classifier_batch` frames, the last one shorter; `gui_actions` (with `double_click_ms`) gives the GUI segments, $C$ and the GUI foreign lines. Calls of $\gamma$ are serialised across workers.
(4) Modes: the start is (False, False, 0) if `starts_session`, else (`overlay_shown` on `luma` of frame 0, False, 0).
(5) Clips: `evidence`, `kept`, `valid_starts`, then `sample` with $L$, $m$, the episode's generator and `accept` = the not yet classified frames of the clip's states with the GUI flag true are classified (in state order, in consecutive chunks of `classifier_batch` frames, the last one shorter), and no state is in `excluded_states`; no clip → reason `no_clip`. Pass 2: one run of the same command, not retried, keeping the frames of the taken clips' states; failing the criterion of (2) aborts the run with `RuntimeError`, the timeout with `TimeoutError`. Each clip is written to the directory `{out_dir}/staging/<k>/<id>.part/` (its files of Datasets); the video is deleted in every case.
(6) Shards, in draw order: shard $k$ of `{out_dir}/shards/` is written by `write_shard` once draw $k$'s candidate, if any, is processed and shard $k - 1$ is written: `records.json`, `state.json`, `options/<version>_<stem>.json` for each record with the reason `malformed`, `options`, `video`, `no_clip` or `null` (byte-identical), and the candidate's first $N - c$ clips in the order taken (all when fewer), renamed from staging into `clips/<id>/`; then `staging/<k>/` is removed. The state stored with shard $k$ is $g$'s state at the end of draw $k$, before draw $k + 1$'s first `integers`, and $c$ after shard $k$. The planner starts draw $k'$ only while fewer than `workers` candidates of draws before $k'$ are not yet written; up to `workers` candidates are processed at once. After the shard that reaches $N$: queued work is cancelled, running work finishes with its results and exceptions ignored, then `staging/` is removed. The outputs do not depend on `workers` or timing.
(7) Continuation: $h$ = `complete_shards` of `{out_dir}/shards/`; for $h \ge 1$ the shards are read one at a time (bar `resume`), accumulating the relpaths and reasons of their records: $g$'s state is set to the `generator` of shard $h - 1$, $c$ to its `clips`, and each pool is its subset's initial pool without the relpaths of that subset's records in shards $0..h-1$, its order kept; drawing continues with draw $h$. (1) has ended in the complete shards when $c \ge N$ or no subset is active.
(8) Rerun: `run.json` (not a dataset) is written by `write_file` at the start of every run, after the check below and before (0): `{"config": <the config's values as written, keys in the order of `PerceptionDataConfig`>, "sha256": {"actions", "clips", "screens", "gui_actions", "overlay", "overlay_screens"}, "classifier": γ_id}`, with the SHA-256 (lowercase hex) of `configs/vpt-actions.yaml` as named by the clips config, of the four config files named by the config and of the catalogue named by the overlay config; at the end of a run that completes it is rewritten with the counts added: `"episodes": {reason or "null": count}` over the records of all shards (reasons that occur), `"clips": c`, accumulated in (7) and as shards are written. Check: if `run.json` exists and any output field (compared as JSON text, `json.dumps` of each value, so the order of `index_urls` and of `required_options` counts), any hash or $\gamma_{id}$ differs from this run's → `RuntimeError(f"{path} holds other values of {names}")`, `names` the list of the differing output fields in the order of Notation, then `sha256.<key>` for each differing hash in the order of the `sha256` keys above, then `classifier`; the other fields may differ between runs. Then `staging/` is removed, the stored indices are used (0), and (7) continues the plan. Starting over = deleting `{out_dir}`. The outputs are complete when `run.json` holds the counts; readers abort while it does not.
(9) Failures: any exception inside the `collect` bar (HTTP after the retries in the planner or in a worker, ffmpeg not starting or timed out, $\gamma$, pass 2, storage) aborts the run: a worker's exception is raised when draw order reaches its draw (the earlier shards written first), the planner's at once; queued work is cancelled, running work finishes, the bar closes, and `collect` re-raises the exception; the one-line message, the last line of stderr, is printed by `main` of `clips/run.py`. ffmpeg's stderr is printed with `tqdm.write(…, file=sys.stderr)` after each run of ffmpeg, decoded as UTF-8 with `errors="replace"`, trailing newlines removed, when not empty.
