## Notation
- $J$ — the engine jar: `{minestudio_dir}/engine/build/libs/mcprec-6.13.jar` (the path MineStudio's `check_engine` requires) — the block's product.
- $D$ — the download directory `{minestudio_dir}/download/`; $Z$ = $D$`/engine.zip`; $S$ = $D$`/engine/build/libs/mcprec-6.13.jar` (the extracted source jar).
- Modules $M$ = (`lwjgl`, `lwjgl-opengl`, `lwjgl-glfw`, `lwjgl-stb`, `lwjgl-openal`, `lwjgl-jemalloc`, `lwjgl-tinyfd`), in this order; for $m \in M$ and $v$ = `lwjgl_version`: classes jar `{lwjgl_url}/{m}/{v}/{m}-{v}.jar`, natives jar `{lwjgl_url}/{m}/{v}/{m}-{v}-natives-linux-arm64.jar`; the $2|M|$ jars in the order: for each $m$, classes then natives.
- Removed entries $R$ of the source jar: a name starting with `org/lwjgl/`; a name matching at its start (`re.match`) `META-INF/versions/[0-9]+/org/lwjgl/`; a name without `/` matching in full (`re.fullmatch`) `(lib)?(lwjgl(_opengl|_stb|_tinyfd)?|glfw(_wayland)?|openal|OpenAL|jemalloc)(32)?\.(so|dll|dylib)(\.git|\.sha1)?`.
- Added entries $A$: from each classes jar, the names starting with `org/lwjgl/` or matching at their start `META-INF/versions/[0-9]+/org/lwjgl/`; from each natives jar, the names starting with `linux/arm64/`; taken in the order of the $2|M|$ jars, entries in each jar's order; a name already written to the new jar is skipped.
- $\rho$ — rate: `steps` / ($t_1 - t_0$), $t_0$ = `time.perf_counter()` right before the first timed step, $t_1$ right after the last; ticks per second.

## Behaviour
### `scripts/setup_env.sh` (block spark-env), two new steps
(5a) `engine-deps`, before (6) `sync` (`uv sync` builds `glcontext` and `imgui` from source on aarch64): packages `openjdk-8-jre xvfb libgl1-mesa-dri libglx-mesa0 build-essential libx11-dev`, listed in the script (as the ffmpeg packages of step (7)). If `dpkg-query -W -f='${db:Status-Status}\n'` of them does not print exactly one line `installed` per package (only the printed lines compared; its exit status ignored; its stderr shown, as in step (7); second-architecture copies, which could add lines, do not occur on the arm64-only Spark — accepted as in step (7)): `sudo apt-get update`, `sudo apt-get install -y <packages>`. Then, whether or not the packages were installed in this run, the combined stdout and stderr of `java -version` are captured (nothing printed; its exit status ignored); if the captured text does not contain `version "1.8.` anywhere (a missing `java` included): stderr gets `setup_env.sh: java on PATH is not Java 8; run "sudo update-alternatives --config java"` and the step fails.
(9) `engine`, after (8) `vlm`: `uv run --locked python -m mcpref.engine.prepare configs/engine.yaml`.

### `prepare` (`python -m mcpref.engine.prepare configs/engine.yaml`)
(0) `load_config`; $D$ removed if present (`shutil.rmtree`).
(1) $J$ exists → `engine: already done` on stderr; exit 0.
(2) Each of the $2|M|$ LWJGL jars, in order, downloaded into memory by `download` of `src/mcpref/http/retry.py` (`http_timeout`, `http_retries`, `retry_delay`); its sha256 (`hashlib.sha256(...).hexdigest()`) compared with `lwjgl_sha256`; a mismatch raises `ValueError(f"{url}: sha256 {actual} != {expected}")`. Nothing is written in (2).
(3) `make_dirs(D)` (`specs/shards.md`); the `engine.zip` bar created; then $Z$ fetched on one `httpx.Client(follow_redirects=True, headers={"Accept-Encoding": "identity"})` by `retried(attempt, retryable, http_retries, retry_delay)` of `src/mcpref/http/retry.py`. One attempt (a function of `prepare.py`): `bar.reset()` and a new `hashlib.sha256()`; `client.stream("GET", engine_url, timeout=httpx.Timeout(http_timeout))`; any `httpx.TransportError` (during the request or the body) is returned; the final status is checked before the body is read: 5xx → the response is returned (body unread, $Z$ untouched); otherwise `raise_for_status()` (any other non-2xx, 3xx included), then a 2xx other than 200 → `ValueError(f"{engine_url}: HTTP {status}")`; on 200, $Z$ is opened for writing (truncated) and the body written chunk by chunk (`iter_bytes()`), each chunk added to the sha256 and to the bar. After `retried`: a last transport error is raised; a last 5xx response → `raise_for_status()`. `TooManyRedirects` and `DecodingError` are not retried ([H]). Then the last attempt's sha256 compared with `engine_sha256`, a mismatch raising as in (2) with `engine_url`.
(4) The member `engine/build/libs/mcprec-6.13.jar` of $Z$ extracted into $D$ (`ZipFile.extract`), giving $S$.
(5) `make_dirs(J.parent)`; a new zip written to `part_path(J)` (`zipfile.ZipFile(part, "w")`, default compression level; a leftover one overwritten): every entry of $S$ not in $R$, in its order, then the entries $A$ from the jars of (2); each entry by `writestr(info, data)` with `info` the source's own `ZipInfo` object, its data recompressed by its compression type: kept are `filename`, `date_time`, `compress_type`, `comment`, `extra`, `create_system`, `create_version`, `extract_version`, `reserved`, `internal_attr` and a non-zero `external_attr`; `writestr` writes `volume` as 0 (0 on every entry of [E]), sets `flag_bits` to 0, an `external_attr` of 0 to `0o600 << 16`, and recomputes `header_offset`, `CRC`, `compress_size`, `file_size` (CPython 3.10.20 `zipfile.py:1616-1635, 1840`; names in the jar are ASCII, so the cleared UTF-8 flag changes nothing); then `publish(part_path(J), J)` (`specs/shards.md` (3)).
(6) $D$ removed; exit 0.
Any `Exception`: exit 1 by `failed("mcpref.engine.prepare", error)` of `src/mcpref/cli/failure.py` (one stderr line `mcpref.engine.prepare: <type>: <message>`); $J$ is never left half-written; a rerun starts again at (0).

### `use_engine(cfg)` and `check` (`python -m mcpref.engine.check configs/engine.yaml`, run by `scripts/check_sim.sh`)
(7) `use_engine(cfg)`: $J$ missing → `FileNotFoundError(f"engine missing: {J}; run scripts/setup_env.sh")` (MineStudio would otherwise wait on its download prompt), nothing set; else `os.environ["MINESTUDIO_DIR"] = str(minestudio_dir)` and `os.environ["MINESTUDIO_GPU_RENDER"] = "0"` (CPU rendering under Xvfb). Precondition, not checked: called before MineStudio is imported (it reads the directory at import, [MS]).
(8) `check`: `load_config`; `use_engine`; then `from minestudio.simulator import MinecraftSim`.
(9) `sim = MinecraftSim(action_type="env", obs_size=render_size, render_size=render_size, seed=seed)` (other arguments at their defaults, [MS]); inside `try` … `finally: sim.close()`: `sim.reset()`; the `check` bar created; `warmup_steps` untimed steps, then `steps` timed ones; a step is `sim.step(sim.noop_action())` (`noop_action` called once per step), then `terminated or truncated` → `RuntimeError(f"episode ended at step {k}")` ($k$ = 1, 2, … over all `warmup_steps + steps` steps), then the bar advanced; the whole step, check and bar update included, lies inside the timed interval of $\rho$ for the timed steps.
(10) After `close`: stdout gets `rate: {ρ:.1f} ticks/s (min {min_rate})` (MineStudio's own stdout lines come before it); $\rho \ge$ `min_rate` → exit 0; else `RuntimeError(f"rate {ρ:.1f} ticks/s below min_rate {min_rate}")`.
Any `Exception` in (8)–(10): exit 1 by `failed("mcpref.engine.check", error)`.
